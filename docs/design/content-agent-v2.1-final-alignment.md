# Content Agent v2.1 最终对齐稿

## 目标

v2.1 用来冻结四个核心页面的视觉、组件和交互取舍，作为后续真实页面重构的唯一对齐依据。

本阶段不继续扩展业务功能，不改接口，不新增未来占位按钮。素材库已经作为第一轮实战样板，后续三个页面按同一套 AppShell、表格、弹窗、状态和输入规则重构。

## 设计读法

- 产品类型：B2B 内容运营后台。
- 使用人群：内容运营、市场运营、管理员。
- 视觉语言：冷静、清爽、商用、信息密度中高。
- 默认密度：真实业务页使用 `standard` 到 `compact`，不在正式系统暴露密度切换。
- 组件策略：先复用 UI Kit v1，再按 v2.1 业务规则补齐页面级组件。

## 全局冻结规则

### 保留

- 左侧固定 Sidebar：内容中台品牌、核心四页入口、系统/团队类入口可保留但不喧宾夺主。
- 顶部 Topbar：页面标题、简短说明、当前用户与权限范围。
- 冷灰背景、白色主面板、浅边框、蓝色主按钮、绿色/橙色/红色状态。
- 表格作为四页主要信息承载，不用大面积营销式卡片。
- 居中 Modal 作为详情、编辑、预览、提示词配置的默认交互。
- 平台使用真实品牌图标或统一平台 logo，不用“抖 / 红 / V / C”这类文字占位。

### 删除

- 无内容的帮助中心、通知、视图设置、分享。
- 不可点击但长得像按钮的标签。
- 解释不清的进度条、流程条、装饰性 KPI 大卡。
- 左下角重复用户信息。当前用户统一放 Topbar。
- 纯占位图、临时文案、假数据按钮。
- 横向挤压导致的操作按钮换行、遮挡和滚动条。

### 未来占位

这些能力可以在设计稿中作为路线说明，但当前真实页不放可点击入口：

- 帮助中心。
- 通知中心。
- 视图设置。
- 高级筛选。
- 分享素材。
- 素材分析。
- 团队管理与角色权限的二级页面。
- 真实质量评分第二层：素材解析质量、用户反馈、飞书状态、发布效果数据。

## 四页最终取舍

### 1. 素材库

当前状态：第一轮实战样板，后续继续在真实页上小步修正。

保留：

- 链接录入卡：从剪贴板录入、识别并预览、确认下载入库。
- Excel / 飞书导入卡：Excel 上传、模板下载、飞书多维表格链接输入、识别预览、确认下载入库。
- 素材列表：真实数据渲染，支持搜索、平台/状态筛选、选择生成输入。
- 素材预览弹窗：视频、标题、状态、标签、下载、查看详情。
- 素材详情弹窗：基础信息、链接、标签、字幕文本、AI 摘要、使用历史、操作记录。
- 待补字幕状态：显示“补充字幕”，调用真实字幕提取并写回素材。
- 下载本地：通过视频原始 URL 或本地素材文件保存。

删除：

- 素材概览大统计区。
- 分享按钮。
- 帮助中心、通知。
- 高级筛选按钮。
- 二次确认入库弹窗。
- 弹窗里的“加入本次 / 移出本次”模糊文案，统一为“加入生成输入 / 从生成输入移除”。

未来占位：

- 素材分析。
- 发布效果数据回填。
- 素材质量真实评分。

验收重点：

- 1280px 宽度下表格不横向溢出。
- 预览卡片按钮只保留真实可用动作。
- 待补字幕不暴露 `ASR_API_KEY`、`subtitle:` 等技术字段。
- 所有导入错误用用户语言提示。

### 2. 品牌活动

当前状态：第一轮真实还原已落地，作为后续脚本生成和脚本库重构的参考样板。

真实页入口：

```text
http://127.0.0.1:8782/prototype/simple-agent-campaigns.html?v=campaign-real-ui-kit-v1
```

版本快照：

```text
docs/design/v2.1/campaigns-real-page-v2.1.md
docs/design/v2.1/campaigns-real-page-v2.1-1392x908.png
```

保留：

- 主体表格：商品活动、品牌/渠道、核心卖点、活动规则、价格边界、状态、归属用户、更新时间、操作。
- 新增/编辑品牌活动居中弹窗。
- 品牌矩阵号作为同页 tab 或次级列表。
- 规则自检第一层：价格边界、渠道范围、活动规则完整性。
- 保存后可进入“脚本生成输入”的业务状态。

删除：

- 顶部四个大 KPI 卡作为主视觉。
- “本次生成”“矩阵协同”等解释不清的流程块。
- 没有真实动作的导出、批量导入、视图设置。
- 左下角重复用户卡。
- 图标字母占位。

未来占位：

- 活动批量导入。
- 活动历史版本。
- 渠道投放效果回填。
- 矩阵账号自动同步。

验收重点：

- 编辑弹窗表单字段清楚，必填项、字数、错误提示明确。
- 价格边界和渠道范围必须是用户能理解的业务字段。
- 列表操作不拥挤，次要操作进入更多。

### 3. 脚本生成

当前状态：重构优先级第二。

保留：

- 左右两栏：选择商品活动、选择参考素材。
- 底部输入包摘要：已选活动、已选素材、缺失项、预计生成数量、生成按钮。
- 提示词配置入口，但默认不打扰主流程。
- 本次生成结果只展示当前点击生成后的结果。
- 规则自检第一层：
  - 是否缺价格边界。
  - 是否缺渠道范围。
  - 是否引用未确认价格。
  - 是否 4 段完整。
  - 是否有 CTA。
  - 是否明显复制素材原文。
  - 是否有绝对化表达。

删除：

- 顶部工作流进度条。
- 大面积“生成工作台”说明卡。
- 默认展开复杂提示词配置。
- 历史脚本混在本页。
- 空状态里解释功能的长文案。

未来占位：

- 真实质量评分第二层。
- 发布数据反馈参与生成策略。
- 多模型对比生成。
- 生成耗时和队列监控。

验收重点：

- 选择区不使用小滚动框装复杂表格。
- 主生成动作始终在可见区域。
- 规则自检显示的是业务风险，不是技术检查项。

### 4. 脚本库

当前状态：重构优先级第三。

保留：

- 状态 tab：全部、待复盘、已采用、待改、弃用、优质样例、飞书已同步。
- 工具栏：搜索、状态、商品活动、归属用户、创建时间。
- 主表格：脚本标题/Hook、商品活动、参考素材、状态、质量自检、飞书同步、创建时间、归属用户、操作。
- 脚本详情大弹窗：左侧正文，右侧脚本信息、质量自检、参考素材、操作历史。
- 弹窗 tabs：脚本正文、脚本分析、输入包、操作记录。
- 操作：预览、采用、待改、弃用、样例；窄屏时次要操作进更多。

删除：

- 顶部状态说明流程块。
- 不能点击却像按钮的历史脚本资产标签。
- 无内容的导出和视图设置。
- 长飞书文档名常驻展示。
- 右侧 Drawer 式详情，改成居中大弹窗。

未来占位：

- 飞书同步详情。
- 脚本版本比较。
- 发布效果回填。
- 质量趋势报表。

验收重点：

- 脚本正文可读，不被压成窄列。
- 操作列不遮挡、不换行。
- 状态和质量自检必须能解释脚本为什么可用或不可用。

## 重构顺序

1. 素材库：继续按真实数据细修，作为样板页冻结。
2. 品牌活动：按 v2.1 规则重构为 UI Kit AppShell + 表格 + 编辑弹窗。
3. 脚本生成：重构左右选择区、输入包摘要、规则自检、当前生成结果。
4. 脚本库：重构状态 tab、脚本表格和详情大弹窗。
5. 抽组件：从四页真实代码反推稳定组件，不先抽空泛组件。

## 验收方式

- 每页在 1280x800、1366x768、1440x900 验证。
- 页面内不出现横向滚动条，除非是明确的超宽审计表。
- 文案不出现内部字段名，例如 `batchText`、`ASR_API_KEY`。
- 所有按钮都必须有真实动作；暂时无动作则不展示。
- 弹窗头部和正文无断层，底部按钮同高同线。
- 所有图标来自统一体系或平台品牌图标。
