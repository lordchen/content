# Content Agent v2 四页还原清单

## 基准设计稿

- `docs/design/content-agent-v2-materials.png`
- `docs/design/content-agent-v2-campaigns.png`
- `docs/design/content-agent-v2-generate.png`
- `docs/design/content-agent-v2-scripts.png`

后续静态页和真实业务页重构都以这四张图为还原基准。组件库不是自由发挥的样式合集，而是为还原这四页抽象出的系统。

## 全局框架

- 左侧 Sidebar 宽度、品牌区、分组导航、active 状态保持一致。
- Topbar 高度、标题位置、帮助中心、通知、用户头像、用户名称位置保持一致。
- 页面背景为冷灰 off-white，主内容卡片为白色，边框极浅。
- 不使用无意义进度条、占位图、文字图标占位。
- 图标使用统一线性图标；平台图标使用品牌图标。
- 页面默认信息密度接近设计稿，可通过 density token 微调，但真实页还原优先。

## 素材库

设计结构：

- 顶部为左右两张导入卡：链接录入、Excel / 飞书导入。
- 其下为一条轻量统计带：全部素材、图片、视频、音频、文档、存储空间。
- 主体为素材列表表格。
- 素材预览使用居中卡片弹窗，覆盖在表格上方。

关键还原点：

- 链接录入卡 textarea 高度、按钮位置、标题和说明层级要与设计稿一致。
- Excel / 飞书导入为左右两个虚线区域，中间有“或”的分隔。
- 统计区必须是窄条，不做大 KPI 卡。
- 表格列宽要能容纳缩略图、平台、状态、标签、时间和操作；不默认横向滚动。
- 预览弹窗包含视频预览、标题、尺寸 / 时长 / 大小 / 格式、标签、下载、分享、查看详情。
- 行操作使用图标按钮：下载、分享、更多。

## 品牌活动

设计结构：

- 顶部为页面标题和说明。
- 主 tab：已录入品牌活动 / 品牌矩阵号。
- 操作区：新增品牌活动、批量导入、导出、搜索、筛选、视图设置。
- 中部为四个统计卡：有效活动、待补价格、缺渠道、本次可用于生成。
- 主体为活动表格。
- 编辑弹窗居中显示。

关键还原点：

- 品牌活动编辑弹窗宽度、表单行距、右侧字数提示、底部按钮对齐要还原。
- 表格不使用产品占位图。
- 表格字段突出商品活动、卖点、活动规则、价格边界、状态、归属用户、更新时间、操作。
- 操作列使用图标按钮，不出现文字挤压。

## 脚本生成

设计结构：

- 左右两栏：选择商品活动 / 选择参考素材。
- 右上角提示词配置入口。
- 左栏为活动 picker table。
- 右栏为素材 picker table。
- 下方为已选输入包和缺失项检查。
- 本次生成结果在底部列表展示。
- 提示词配置使用居中弹窗。

关键还原点：

- 商品活动和参考素材必须左右排列，不回到上下堆叠。
- picker table 不使用小滚动框承载复杂选择。
- 已选输入包固定为底部横向摘要，展示已选活动、缺失项、预计生成脚本数和生成按钮。
- 提示词配置弹窗高度稳定，tab 切换不抖动。
- 本页只展示当天 / 本次相关生成结果；历史脚本去脚本库。

## 脚本库

设计结构：

- 顶部为状态筛选条：全部、待复盘、已采用、待改、弃用、优质样例、飞书已同步。
- 下方工具栏：搜索、状态、商品活动、归属用户、创建时间、更多筛选、导出、视图设置。
- 主体为脚本表格。
- 脚本详情居中大弹窗，左侧正文，右侧脚本信息 / 质量自检 / 参考素材 / 操作历史。

关键还原点：

- 状态筛选条是可点击 tab，不是普通标签。
- 脚本详情弹窗正文可读，不能窄列挤压。
- 弹窗 tabs：脚本正文 / 脚本分析 / 输入包 / 操作记录。
- 操作列按钮：预览、采用、待改、弃用、样例、更多；窄屏时次要操作收进更多。
- 顶部飞书状态显示“飞书已同步”，不长时间展示飞书文档名。

## 组件库反推要求

UI Kit 必须至少覆盖这些业务组件：

- AppShell
- TopbarUserMenu
- StatusTabs
- ImportCard
- UploadDropzonePair
- MetricStrip
- DataToolbar
- DataTable
- RowActionGroup
- PlatformLogo
- EditModal
- PreviewModal
- RichAssetScriptModal
- PromptConfigModal
- SelectedInputSummary
- Toast / InlineStatus

## 验收规则

- 静态模板必须在 1280x800、1366x768、1440x900 三个尺寸下截图对比。
- 常规表格不应出现横向滚动条。
- 所有弹窗高度必须受控，tab 切换不抖动。
- 所有图标必须来自统一体系或品牌图标，不能用文字占位。
- 长文本在列表中截断，在弹窗中展示全文。
- 操作按钮不遮挡、不贴边、不换行。
