Imagegen 商用方向

这一版改为正式对外商用产品的视觉方向：保留专业 B2B 工作台结构，同时增加更丰富的运营色彩、右侧洞察面板、健康度图表、动态流和更精致的编辑弹窗。

  • 不再是单纯白底表格页面，主区有品牌化 hero、彩色指标卡和上下文洞察。
  • 弹窗字段对齐、状态芯片、底部操作和同步提示按商用品质重新定义。
  • 色彩使用 blue、teal、amber、coral、lavender 的轻量组合，不走紫色 AI 风。
  • 静态原型将按此方向迁移，先落品牌活动页，再统一四页。
