# 内容生产 Agent｜使用反馈与问题收集

> 用途：组织内成员在试用系统时，统一记录问题、截图、输入提示词和生成结果，方便产品和开发快速复现、判断优先级并修复。

## 反馈填写规则

每次反馈请尽量按同一格式填写，不需要写长篇说明，但必须包含以下四项：

| 必填项 | 说明 |
| --- | --- |
| 问题描述 | 简单说明你遇到了什么问题，发生在哪个页面或步骤 |
| 截图 | 直接粘贴问题截图，最好包含页面 URL、按钮或异常提示 |
| 提示词/输入 | 粘贴当时输入的视频链接、Excel、飞书表格链接、主题、商品信息或提示词 |
| 实际结果与期望结果 | 写清楚系统实际输出了什么，以及你希望它怎么表现 |

## 生成质量反馈专用模板

当问题不是按钮或页面 Bug，而是“脚本生成得不好”，请使用这个模板。

**主题/商品：**  
**选择的素材：**  
**选择的品牌活动：**  
**生成条数：**  
**质量要求：**  
**输出方式：** 分镜脚本 / 口播脚本 / 表格脚本  

**使用的提示词或质量干预要求：**  

**系统生成结果：**  
请粘贴原始生成结果。

**哪里不好：**  
- 开头不够强
- 没有读懂商品
- 没有使用素材
- 过度照搬素材
- 信息不准确
- 不适合拍摄
- 不符合品牌语气
- 其他：

**希望优化成什么样：**  
请给出 1-2 条明确要求，例如“开头更短”“多写到店动作”“不要承诺最低价”。

**可参考的好结果：**  
如果有更好的脚本或人工改写版本，请粘贴在这里。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 待确认 | 还没判断是否为问题，或信息不足 |
| 已复现 | 已经确认能复现 |
| 修复中 | 已进入开发处理 |
| 待验证 | 已修复，等待反馈人确认 |
| 已关闭 | 已解决或不再处理 |
| 暂缓 | 不是第一期范围，后续再看 |

## 反馈建议

为了提高处理效率，建议每个问题单独写一条反馈。不要把多个问题混在同一条里，尤其是“页面样式问题”和“脚本生成质量问题”要分开记录。
