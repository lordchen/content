# 内容生产 Agent V1 内测指南

## 你要完成的一轮测试

1. 打开素材库。
2. 使用内测账号登录。
3. 确认至少有 1 条参考素材被选中。
4. 打开品牌活动，录入或确认 1 条品牌活动商品。
5. 打开脚本生成，填写今日主题。
6. 选择商品活动和参考素材。
7. 点击生成脚本。
8. 查看脚本结果，标记采用、待改或弃用。

## 内测账号

- 账号：`admin`
- 密码：`simple-agent-v1`

如果管理员设置了新的启动密码，以管理员同步的密码为准。

## 使用边界

- 生成脚本只作为候选稿。
- 发布前必须人工复核价格、活动权益、库存、门店范围和版权风险。
- 不要把原视频文案直接发布。
- 不要录入账号密码、客户隐私、订单信息或其他敏感数据。

## 反馈记录

每轮内测请记录：

- 输入了什么素材
- 输入了什么活动商品
- 生成是否成功
- 生成结果是否可拍
- 哪些地方需要人工大改
- 页面哪里不好理解
- 是否出现报错，报错文案是什么

## 常见问题

### 生成失败

这是正常失败，不会自动模拟兜底。请记录页面报错，并检查：

- Codex CLI 是否可用
- 是否至少选择了 1 条素材
- 是否至少选择了 1 条活动商品
- 提示词是否要求了无法从输入中得到的信息

### 页面打不开

先运行：

```bash
scripts/simple_agent_start.sh
```

再打开：

http://127.0.0.1:8782/prototype/simple-agent-materials.html?v=simple-agent-v1-beta-auth
