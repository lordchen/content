# 固定对标账号池填写模板

用于沉淀每天必须看的固定对标账号，后续会直接进入系统的对标账号池，不再依赖临时聊天补充。

## 一、使用说明

请按“一个账号一行”的方式填写，不要把多个账号塞进同一行。

这份表的目标不是收藏链接，而是让系统知道：

- 这个账号为什么值得跟
- 它更像哪一种对标
- 我们希望从它身上学什么
- 哪些内容结构可以进入脚本候选层

## 二、填写原则

### 1. 只放真正会每天或每周反复看的账号

不要把“偶尔看到一次”的账号放进固定池。

### 2. 一个账号只写一个主定位

例如：

- 品牌官方号
- 本地团购号
- 穿搭种草号
- 探店转化号
- 门店活动号

不要同一个账号写 4-5 个定位。

### 3. 优先写“为什么跟”

系统真正要用的是你们跟这个账号的理由，不只是名字和链接。

## 五、填写建议

建议先只填 `10-20` 个最关键账号，不要第一版就堆太多。

优先顺序建议：

1. 品牌官方号
2. 同类团购转化号
3. 同类穿搭种草号
4. 本地门店活动号

## 六、后续系统怎么用这份表

填完后，这份表会直接转成：

- 固定对标账号池
- 对标账号抓取名单
- 脚本结构参考来源
- 每日脚本候选补充来源
